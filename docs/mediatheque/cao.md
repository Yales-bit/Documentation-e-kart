# Fichiers CAO

## Organisation des fichiers

```
assets/cao/
├── chassis/
│   ├── chassis_complet.step
│   ├── chassis_complet.f3d
│   └── plans/
│       ├── plan_cadre.pdf
│       └── plan_pieces.pdf
├── moteur/
│   └── support_moteur.step
├── batterie/
│   └── boitier_batterie.step
└── assemblage/
    └── kart_complet.step
```

## Formats disponibles

| Format | Logiciel | Usage |
|:---|:---|:---|
| `.step` / `.stp` | Universel | Échange CAO standard |
| `.f3d` | Fusion 360 | Fichier natif, éditable |
| `.stl` | Impression 3D | Maillage pour slicing |
| `.dxf` | Découpe laser/plasma | Profils 2D |
| `.pdf` | Plans cotés | Documentation, fabrication |
